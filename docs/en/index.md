# kyuar documentation

kyuar makes QR codes without leaving Telegram: inline in any chat, in a private chat with the bot, and in a full editor that opens as a Mini App. It also reads QR codes from the camera, from photos, and from images in groups. The docs exist in three languages: English, Uzbek and Russian.
