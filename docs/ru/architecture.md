## Карта репозитория

Монорепозиторий на pnpm workspace. Для каждой задачи есть рецепт `just`.

| Путь                  | Что там                                                                                                                         |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `apps/web`            | Приложение Next.js 16: Mini App, `/api/qr`, `/api/render`, `/api/share`, `/api/bot` (webhook)                                   |
| `apps/bot`            | Обработчики grammY, тексты бота, poller для разработки и скрипт webhook                                                         |
| `packages/qr`         | Рендерер стилизованного SVG: формы, заливки, полутон, место под логотип, формула палитры, чтение изображений (`@kyuar/qr/scan`) |
| `packages/qr-encoder` | QR-энкодер, взятый из paulmillr/qr и дополненный типом для каждого модуля                                                       |
| `packages/shared`     | Схемы zod, кодек `/api/qr`, проверка initData, разбор отсканированного содержимого, безопасность ссылок, локали, форматы цвета  |
| `packages/ui`         | Компоненты shadcn/ui на Base UI и дизайн-токены                                                                                 |
| `packages/env`        | Схема envin, единственный источник правды для конфигурации                                                                      |
| `brand/`              | Логотип, иконки и анимации Lottie                                                                                               |
| `docs/`               | Эти документы                                                                                                                   |

## Технологии

- **Среда выполнения**: Node.js 24, TypeScript 5.9, pnpm 11.
- **Веб**: Next.js 16 (App Router, Turbopack), React 19, Tailwind CSS 4.
- **UI**: shadcn/ui на Base UI, иконки lucide, `@tma.js/sdk-react` для Telegram.
- **Бот**: grammY 1.46, Bot API 10.
- **Изображения**: resvg для SVG → PNG, sharp для JPEG, логотипов и фото.
- **Хранилище**: Redis для лимитов запросов и недолго живущих готовых изображений. Базы данных нет.
- **Качество**: oxlint, oxfmt, react-doctor, knip, vitest, lefthook, commitlint.

## Путь запроса

```text
Telegram client ─┬─ inline query / message ─→ /api/bot (webhook) ─→ grammY handlers
                 │                                                  └─ photo_url → /api/qr
                 └─ Mini App ─→ page.tsx ─→ editor (renders in a Web Worker)
                                         ├─ POST /api/share  → savePreparedInlineMessage
                                         └─ POST /api/render → Redis (10 min) → downloadFile
```

- **Inline-режим и личные чаты.** Бот отвечает URL фотографий, которые ведут на `/api/qr`. В URL лежат данные, формат и только те части стиля, которые отличаются от стандартных, в виде base64url JSON. Поэтому одинаковые коды получают один URL, который можно кэшировать.
- **Редактор.** Рисует предпросмотр в Web Worker, поэтому перетаскивание цвета никогда не блокирует страницу. Второй worker читает фото для сканера и запускает тест сканирования.
- **Коды с логотипом или полутоновой картинкой.** Их нельзя описать URL. `/api/render` перекодирует изображения через sharp, рисует код и хранит PNG, PNG 2048 px, JPEG и SVG в Redis десять минут. Telegram скачивает их и делится ими по адресу `/api/render/<id>`.
- **Отправка.** `shareMessage()` нужно сообщение, подготовленное ботом. Поэтому Mini App обращается к `/api/share`, который проверяет `initData` и вызывает `savePreparedInlineMessage`.

## Правила, в которых легко ошибиться

Полный список есть в [AGENTS.md](../../AGENTS.md). Самые важные:

- Никогда не доверяйте `initData` от клиента. Каждый запрос, который действует от имени пользователя, проверяет его на сервере через `@tma.js/init-data-node`.
- Переменных `NEXT_PUBLIC_*` нет. `APP_URL` и `BOT_USERNAME` читаются во время работы, поэтому один Docker-образ работает где угодно.
- Кнопки `web_app` работают только в личных чатах. Всё, что может попасть в группу, ведёт на `t.me/<bot>?startapp=<base64url>`.
- Inline-фото должны быть в JPEG. Бот ссылается на `/api/qr?t=jpg`.
- resvg нужно запускать с `loadSystemFonts: false`. В QR SVG нет текста, а загрузка шрифтов занимает секунды.
- Задавайте стиль по типу модуля из энкодера. Никогда не ищите угловые узоры заново по координатам.
- UI не следует `themeParams` Telegram. Выбранная тема QR задаёт `--theme` и `--theme-ink`, и все токены выводятся из них.

## Конфигурация

Вся конфигурация лежит в корневом `.env`, её проверяет `packages/env`.

| Переменная                | Обязательна | Значение                                                            |
| ------------------------- | ----------- | ------------------------------------------------------------------- |
| `BOT_TOKEN`               | да          | Токен от BotFather                                                  |
| `BOT_WEBHOOK_SECRET`      | да          | Не меньше 16 символов, проверяется при каждом вызове webhook        |
| `BOT_USERNAME`            | да          | Имя бота без `@`, используется в ссылках `t.me`                     |
| `APP_URL`                 | да          | Публичный адрес веб-приложения. В продакшене должен быть `https://` |
| `REDIS_URL`               | нет         | Включает лимиты запросов и рендер изображений для отправки          |
| `RATE_LIMIT_PER_MINUTE`   | нет         | Запросов в минуту на клиента к `/api/qr`, по умолчанию 120          |
| `CLIENT_IP_HEADER`        | нет         | Заголовок с реальным IP клиента, по умолчанию `x-forwarded-for`     |
| `CLOUDFLARE_TUNNEL_TOKEN` | нет         | Именованный туннель для `just tunnel`                               |

## Куда добавлять новый код

| Изменение                                    | Место                                                                          |
| -------------------------------------------- | ------------------------------------------------------------------------------ |
| Новая форма точки, рамки или центра          | `packages/qr/src/figures/`. Она должна пройти тест декодера в `render.test.ts` |
| Новая настройка стиля                        | `packages/qr/src/style.ts`, затем схема zod в `packages/shared/src/schema.ts`  |
| Новый элемент управления в редакторе         | `apps/web/src/components/editor/controls.tsx` в виде `SheetRow`                |
| Примитив UI                                  | `just ui-add <name>`. Никогда не стилизованный вручную div                     |
| Текст в Mini App                             | `apps/web/src/i18n/{en,uz,ru}.ts`, все три сразу                               |
| Текст в боте                                 | `apps/bot/src/i18n.ts`, все три языка                                          |
| Скопированный или перенесённый сторонний код | Укажите авторов в `THIRD_PARTY_NOTICES.md` и README                            |
