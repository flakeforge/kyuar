## Что делает бот

Бот написан на grammY в `apps/bot`. В продакшене он работает внутри веб-приложения: Telegram вызывает `POST /api/bot`, а grammY проверяет заголовок `BOT_WEBHOOK_SECRET`. При разработке он работает отдельно через long polling.

| Где                        | Создаёт коды  | Читает коды                         |
| -------------------------- | ------------- | ----------------------------------- |
| Inline-режим (`@bot text`) | Да, в 8 темах | —                                   |
| Личный чат                 | Любой текст   | Любое фото или файл-картинку        |
| Группа                     | —             | При упоминании или с `/scan`        |
| Guest Chat Mode            | —             | При упоминании в чате, где бота нет |

Обработчики регистрируются в `apps/bot/src/index.ts` в таком порядке: команды, inline, сканирование.

## Настройка BotFather

В [@BotFather](https://t.me/BotFather) для вашего бота:

1. **Main Mini App**: Bot Settings → Configure Mini App → Enable, и укажите URL равный `APP_URL`. Без этого ссылки `t.me/<bot>?startapp` из групп ничего не открывают.
2. **Inline-режим**: `/setinline` с короткой подсказкой, например `ссылка или текст`.
3. **Guest Chat Mode**: включите, чтобы читать коды в чатах, где бот не состоит.
4. **Group privacy** можно оставить включённым. С ним бот всё равно получает сообщения, где его упоминают, и `/scan@bot`. Простой `/scan` приходит только в некоторых случаях, например когда в группе нет других активных ботов. Выключите privacy, если участники всегда должны иметь возможность написать `/scan`.

Меню команд не задаётся вручную. Его публикуют `just dev` и `just webhook-set`.

## Команды

| Команда  | Личный чат                                                                                                                  | Группа                               |
| -------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| `/start` | Приветствие и кнопка «Открыть редактор»                                                                                     | —                                    |
| `/scan`  | Читает картинку в сообщении или в сообщении, на которое ответили. Без картинки показывает справку и кнопку «Открыть сканер» | То же, но кнопка — ссылка `startapp` |
| `/help`  | Как пользоваться ботом                                                                                                      | То же                                |

Меню публикуется на английском (по умолчанию), узбекском и русском через `setMyCommands` и `language_code`.

## Inline-режим

`@bot <text>` в любом чате возвращает до 8 фото, по одному на тему. Каждый результат — URL JPEG на `/api/qr`, потому что inline-результаты Telegram не показывают SVG. Подпись — это текст, а кнопка «Изменить в kyuar» открывает Mini App с тем же текстом.

Пустой запрос вместо результатов показывает кнопку «Открыть редактор kyuar». Результаты кэшируются на 60 секунд для каждого пользователя.

Сначала текст классифицируется: почта становится `mailto:`, номер телефона в формате `+` становится `tel:`, а строки `WIFI:` остаются как есть.

## Личный чат

- **Текст.** Бот отвечает QR-фото в стандартной теме и кнопкой «Открыть редактор», которая несёт текст. На текст длиннее вместимости одного кода приходит короткая ошибка. Текст, который начинается с `/`, остаётся обработчикам команд.
- **Фото или файл-картинка.** Бот скачивает файл (до 10 MB), поворачивает и уменьшает его через sharp и читает код. В ответе есть тип содержимого, само содержимое и предупреждения о ссылке. У ссылки есть кнопка «Открыть ссылку», если её схема не опасна. У каждого результата есть кнопка «Оформить этот код».

Ответы — обычный текст, поэтому отсканированное содержимое не может внедрить форматирование.

## Группы и Guest Chat Mode

В группах и супергруппах бот читает картинку, только когда его просят:

- Ответьте на фото сообщением `@bot` или `/scan`.
- Добавьте `@bot` или `/scan` в подпись к фото.

Всё остальное, включая обычный текст, он игнорирует. Из сообщений в группах он не создаёт QR-коды.

С **Guest Chat Mode** пользователь может упомянуть бота в чате, где бота нет. Telegram присылает обновление `guest_message`, и бот отвечает через `answerGuestQuery`: статьёй с результатом сканирования. Для этого `guest_message` должен быть в `allowed_updates`. `ALLOWED_UPDATES` в `apps/bot/src/config.ts` уже его включает.

## Ссылки на Mini App

| Ссылка                            | Где работает          | Для чего                                |
| --------------------------------- | --------------------- | --------------------------------------- |
| Кнопка `web_app` на `APP_URL`     | Только в личных чатах | «Открыть редактор», «Открыть сканер»    |
| `APP_URL?data=<text>`             | Только в личных чатах | Редактор с заполненным текстом          |
| `APP_URL?mode=scan`               | Только в личных чатах | Открывается на вкладке «Сканировать»    |
| `t.me/<bot>?startapp=<base64url>` | Везде                 | «Изменить в kyuar», «Оформить этот код» |
| `t.me/<bot>?startapp=scan`        | Везде                 | «Открыть сканер» в группах              |

Кнопки `web_app` не работают в группах и каналах, поэтому всё, что можно переслать, использует `startapp`. Если текст не помещается в параметр запуска, редактор открывается пустым.

## Webhook и polling

```bash
just webhook-set     # set APP_URL/api/bot, drop pending updates, publish commands
just webhook-info    # show status
just webhook-delete  # remove the webhook (asks first)
just bot             # long polling for development
```

`just bot` не запускается, пока установлен webhook. Это защищает рабочего бота от машины разработчика. Для разработки используйте отдельного бота.

## Языки

`botMessages(language_code)` в `apps/bot/src/i18n.ts` выбирает английский, узбекский или русский. Для любого другого языка используется английский. В узбекском используются буквы `ʻ` и `ʼ`, а не ASCII-кавычки.
