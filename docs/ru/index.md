# Документация kyuar

kyuar создаёт QR-коды, не выходя из Telegram: через inline-режим в любом чате, в личном чате с ботом и в полном редакторе, который открывается как Mini App. Он также читает QR-коды с камеры, с фото и с картинок в группах. Документация есть на трёх языках: английском, узбекском и русском.
