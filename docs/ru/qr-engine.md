## Конвейер

```text
text ─→ encoder (matrix + kind per module) ─→ renderQr(style) ─→ SVG ─┬─ editor preview
                                                                      ├─ resvg ─→ PNG
                                                                      └─ sharp ─→ JPEG
```

Движок живёт в двух пакетах без кода фреймворков:

- `packages/qr-encoder` превращает текст в матрицу модулей.
- `packages/qr` превращает матрицу в строку стилизованного SVG. Одна и та же функция работает в Web Worker редактора, в `/api/qr` и в `/api/render`, поэтому код везде выглядит одинаково.

## Энкодер и типы модулей

Энкодер взят из [paulmillr/qr](https://github.com/paulmillr/qr) и дополнен. Кроме тёмного или светлого значения он записывает тип каждого модуля:

| Тип                                             | Значение                                         |
| ----------------------------------------------- | ------------------------------------------------ |
| `Data`                                          | Биты данных и коррекции ошибок                   |
| `FinderRing`, `FinderGap`, `FinderEye`          | Три угловых квадрата: рамка, промежуток, центр   |
| `Separator`                                     | Светлая граница вокруг каждого углового квадрата |
| `AlignmentRing`, `AlignmentGap`, `AlignmentEye` | Маленькие квадраты в больших кодах               |
| `Timing`                                        | Пунктирные линии между угловыми квадратами       |
| `Format`, `Version`, `DarkModule`               | Служебные данные кодирования                     |

Рендерер задаёт стиль каждого слоя по типу. Он никогда не угадывает положение угловых квадратов по координатам.

## Стиль

`QrStyle` в `packages/qr/src/style.ts` описывает всё, что можно изменить:

| Поле                             | Значение                                                                 | По умолчанию           |
| -------------------------------- | ------------------------------------------------------------------------ | ---------------------- |
| `ecc`                            | Коррекция ошибок: `L`, `M`, `Q`, `H`                                     | `H`                    |
| `boostEcc`                       | Брать уровень выше, если он помещается в ту же версию                    | `true`                 |
| `minVersion`                     | Наименьшая версия QR                                                     | `1`                    |
| `mask`                           | Фиксированная маска или `null` для лучшей                                | `null`                 |
| `margin`                         | Поля в модулях                                                           | `2`                    |
| `background`, `backgroundRadius` | Заливка фона и радиус углов (0 — квадрат)                                | Lilac, `0.5`           |
| `data`                           | Форма и заливка модулей данных                                           | `fluid`                |
| `finderOuter`, `finderInner`     | Рамки в углах и точки в углах                                            | `dot`, `extra-rounded` |
| `alignment`                      | Рисовать метки выравнивания как пиксели (`data`) или как углы (`finder`) | `data`                 |
| `timing`                         | Заливка пунктирных линий                                                 | —                      |
| `logo.ratio`                     | Доля кода, освобождённая под логотип, 0 — без логотипа                   | `0`                    |

Заливка бывает сплошной, линейной (с углом) или радиальной, и у каждой есть цветовые точки. Градиенты используют `userSpaceOnUse`, поэтому один градиент идёт через весь код, а не начинается заново в каждом модуле.

## Формы

Формы — это функции, которые возвращают данные пути SVG. Они лежат в `packages/qr/src/figures/`. Формы точек и углов основаны на [@liquid-js/qr-code-styling](https://github.com/liquid-js/qr-code-styling), см. [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

- **Пиксели** (`DOT_FIGURES`): `square`, `dot`, `rounded`, `extra-rounded`, `classy`, `classy-rounded`, `fluid`, `wave`, `heart`, `star`, `diamond`, `circuit`, полосы, блоки и другие. Многие смотрят на соседей, поэтому линии и пятна соединяются.
- **Рамки в углах** (`FINDER_OUTER_FIGURES`): `square`, `rounded`, `extra-rounded`, `dot`, `classy`, `inpoint`, `outpoint`, `center-circle`.
- **Точки в углах** (`FINDER_INNER_FIGURES`): тот же набор плюс `heart`, `pentagon`, `hexagon`, `octagon`, `diamond`.

Чтобы добавить форму, добавьте её в нужную таблицу. Тесты форм и тест декодера в `render.test.ts` должны пройти. Форма, которая красиво выглядит, но не сканируется, — это баг.

## Цвета и формула палитры

Редактор показывает один основной цвет. `derivePalette(base, dark)` в `palette.ts` превращает его в полную палитру:

1. Фон — мягкий оттенок того же тона (яркость OKLCH 0.95) или глубокий тёмный (0.2) для тёмного фона.
2. Пиксели сохраняют тон и меняют яркость, пока контраст с фоном не достигнет 7:1.
3. Рамки в углах отходят ещё на шаг. Точки в углах сохраняют основной цвет, если у него уже есть 4.5:1, поэтому цвет бренда остаётся.

«Расширенные» в редакторе задают каждую часть вручную. Если снова сменить основной цвет, эти настройки заменятся, и редактор об этом предупреждает.

12 готовых тем лежат в `themes.ts`. По умолчанию — Lilac.

## Логотип

При `logo.ratio > 0` энкодер освобождает квадрат в центре и включает ECC `H`, чтобы недостающие модули восстановила коррекция ошибок. Рендерер принимает только href вида `data:image/...;base64`. На сервере sharp декодирует и заново кодирует каждое загруженное изображение, прежде чем оно попадёт в SVG.

## Полутоновые картинки

Полутон рисует картинку самим кодом. Он основан на статье Chu et al., _Halftone QR Codes_ (SIGGRAPH Asia 2013) и написан по ней:

1. Каждый модуль делится на 3×3 подмодуля.
2. Центральный подмодуль модуля данных всегда хранит настоящее значение. Телефоны читают центр, поэтому код по-прежнему сканируется.
3. Служебные узоры (угловые квадраты, пунктир, метки выравнивания) остаются сплошными.
4. Остальные подмодули берутся из картинки с дизерингом Floyd–Steinberg.

В редакторе можно менять размер точки (`centerRatio`) и контраст.

## Проверки сканирования

Три уровня ловят коды, которые не сканируются:

- `renderQr` возвращает предупреждение, если контраст любой краски с фоном ниже 4.5:1.
- Редактор предупреждает о тонких полях или их отсутствии и о слишком длинном тексте.
- «Тест сканирования» рисует текущий дизайн в worker и читает его в четырёх условиях: обычном, мелком (132 px), размытом и тусклом. Результат: читается хорошо, средне или плохо.

## Чтение кодов

`decodeImage` из `@kyuar/qr/scan` читает пиксели RGBA через `qr/decode.js`. Одна и та же функция работает в сканере Mini App (в worker) и в боте (после того как sharp уменьшит фото до 1600 px максимум).

`parseScanned` в `packages/shared` распознаёт содержимое: ссылку, Wi-Fi, контакт (MECARD и vCard), почту, телефон, SMS, место и обычный текст. `checkLink` отмечает опасные ссылки:

| Код             | Значение                                         |
| --------------- | ------------------------------------------------ |
| `unsafe-scheme` | Не `http` и не `https` (например, `javascript:`) |
| `insecure`      | Обычный `http`                                   |
| `shortener`     | Известный сокращатель ссылок                     |
| `lookalike`     | Буквы подражают названию другого сайта           |
| `ip-address`    | Голый IP-адрес вместо имени                      |
| `credentials`   | Логин и пароль внутри ссылки                     |
