## Три способа создать код

1. **В любом чате.** Напишите `@kyuarbot` и ссылку или текст. Выберите один из появившихся цветных кодов, и он отправится в чат.
2. **В чате с ботом.** Отправьте боту любой текст: ссылку, номер телефона вроде `+998901234567`, адрес почты. Он ответит кодом.
3. **В редакторе.** Нажмите «Открыть редактор» в чате с ботом или кнопку под любым кодом kyuar. В редакторе меняют цвета и формы.

## Редактор

Код находится сверху. Введите или вставьте текст в поле под ним, и код обновляется по мере ввода. Когда вы прокручиваете вниз, код становится меньше, но остаётся на виду.

Каждая строка открывает панель с вариантами:

| Строка             | Что меняет                                                                |
| ------------------ | ------------------------------------------------------------------------- |
| Цвет               | Готовые темы или свои цвета                                               |
| Поля               | Пустое место вокруг кода: «Нет», «Маленькие», «Стандартные», «Большие»    |
| Углы               | Скругление углов фона                                                     |
| Пиксели            | Форма маленьких квадратов, в которых хранятся данные                      |
| Рамки в углах      | Форма трёх больших угловых квадратов                                      |
| Точки в углах      | Форма точки внутри каждого углового квадрата                              |
| Метки выравнивания | Маленькие квадраты в больших кодах, нарисованные как пиксели или как углы |
| Коррекция ошибок   | Сколько повреждений выдерживает код. Выше — надёжнее, но плотнее          |
| Логотип            | Изображение в центре                                                      |
| Картинка           | Фото, нарисованное самим кодом                                            |

«Случайный стиль» выбирает случайное оформление. Если оно не нравится, нажмите «Отменить».

## Цвета

- **Темы**: 12 готовых пар цветов, которые всегда читаются.
- **Свой**: выберите один основной цвет, и kyuar сделает из него фон и все остальные части с достаточным контрастом. «Тёмный фон» меняет его на светлые пиксели на тёмном фоне.
- **Расширенные**: задайте цвет каждой части сами, сплошным цветом или градиентом. Если потом сменить основной цвет, цвета частей заменятся.

Пока вы двигаете палитру, она показывает «Хорошо читается» или «Слишком низкий для чтения».

## Логотип и картинка

- **Логотип**: выберите изображение, затем задайте его размер. Коррекция ошибок переключается на максимальную, потому что логотип закрывает часть кода.
- **Картинка**: выберите фото. Код рисуется мелкими точками, и сквозь них видно фото. Настройте размер точки и контраст, пока и фото, и код не станут чёткими.

## Поделиться и скачать

- **Поделиться** (в Telegram): выберите чат, и код отправится как фото с кнопкой «Сделать свой».
- **Скачать**: выберите формат.

| Формат       | Для чего лучше                                                 |
| ------------ | -------------------------------------------------------------- |
| PNG, 1024 px | Чаты, экраны, сайты                                            |
| PNG, 2048 px | Печать                                                         |
| SVG          | Программы для дизайна и крупная печать. Чёткий в любом размере |

## Чтение кодов

Переключитесь на **Сканировать** внизу редактора.

- **Камерой**: открывает камеру Telegram. Наведите её на код.
- **Из фото**: выберите фото или скриншот с кодом.

Результат показывает, что хранит код, и действия для него:

| Содержимое          | Действия                                      |
| ------------------- | --------------------------------------------- |
| Ссылка              | «Открыть ссылку», «Копировать»                |
| Wi-Fi               | Имя сети, пароль, защита. «Копировать пароль» |
| Контакт             | Имя, телефон, почта, организация              |
| Почта, телефон, SMS | Адрес или номер и сообщение                   |
| Место               | «Открыть карту»                               |
| Текст               | «Копировать»                                  |

«Сделать свою версию» открывает то же содержимое в редакторе. Последние 20 сканов хранятся в разделе «Последние сканы». В Telegram они привязаны к вашему аккаунту на всех устройствах.

Можно также отправить фото кода прямо в чат с ботом, и он ответит, что хранит код.

## Чтение кодов в группах

Добавьте бота в группу, затем:

- ответьте на фото сообщением `@kyuarbot` или `/scan`, или
- напишите `@kyuarbot` в подписи к фото.

Бот ответит на это фото результатом. На другие сообщения он не реагирует.

Если бота нет в группе, всё равно можно упомянуть `@kyuarbot` в ответе на фото. Это работает, когда у бота включён Guest Chat Mode.

## Предупреждения о ссылках

kyuar проверяет каждую отсканированную ссылку и предупреждает, когда что-то не так:

| Предупреждение        | Что это значит                                                          |
| --------------------- | ----------------------------------------------------------------------- |
| Не веб-ссылка         | Она может что-то запустить на устройстве. kyuar никогда её не открывает |
| Не зашифрована (http) | Другие в сети могут увидеть или изменить страницу                       |
| Короткая ссылка       | Не видно, куда она ведёт на самом деле                                  |
| Похожий адрес         | Буквы подражают названию другого сайта. Это частый приём фишинга        |
| Голый IP-адрес        | У ссылки нет имени сайта                                                |
| Логин и пароль        | В ссылке есть логин и пароль                                            |

Ссылка с предупреждением открывается только после второго нажатия.

## Советы, чтобы код всегда читался

- Сохраняйте сильный контраст. Лучше всего читаются тёмные пиксели на светлом фоне.
- Оставляйте поля. «Маленькие» — минимум для большинства телефонов.
- Короткий текст даёт более простой код. Используйте ссылку вместо длинного текста.
- Смотрите «Тест сканирования» под кодом. Он проверяет дизайн в мелком размере, размытым и при тусклом свете.
- Проверьте напечатанный код двумя разными телефонами, прежде чем печатать много.
